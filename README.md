# Teachya

Teachya explains language on your screen. Explanations come from **Gemma 4 31B IT**, an open-weight model from Google DeepMind.

## Model

[Gemma 4 31B IT](https://huggingface.co/google/gemma-4-31B-it) (`google/gemma-4-31B-it`, called as `gemma-4-31b-it`) is the default model. Its trained weights are available to download and run under the [Gemma 4 license](https://ai.google.dev/gemma/docs/gemma_4_license), which is the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

Open-weight means those weights are published under that license. It does not by itself make every part of the model, or this app, open source. The [model card](https://ai.google.dev/gemma/docs/core/model_card_4) describes what the release includes.
